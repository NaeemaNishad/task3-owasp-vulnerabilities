# Task 3 - OWASP Top 10 Vulnerabilities (DVWA)

## 🎯 Objective
Identify and exploit OWASP Top 10 vulnerabilities in a controlled lab environment.

## 🛠 Tools Used
- DVWA (Damn Vulnerable Web Application)
- Burp Suite
- Kali Linux

---

## 🔍 Vulnerabilities Covered

1. SQL Injection
2. Cross-Site Scripting (XSS)
3. Cross-Site Request Forgery (CSRF)
4. File Inclusion (LFI/RFI)
5. Burp Suite Testing (Intercept + Intruder)
6. Security Headers Analysis
